🚀 New Flexible API

Flexible data handling, form integration, and powerful new features

1. Custom Object Structure NEW

Use your own data structure! Specify which properties to use for value, display, and other fields using valueMember and displayValueMember. 

// Your custom data structure
const users = [
  { userId: 1, fullName: 'John Doe', email: 'john@example.com', role: 'Admin' },
  { userId: 2, fullName: 'Jane Smith', email: 'jane@example.com', role: 'User' },
  ...
];

// Configure which properties to use
multiselect.valueMember = 'userId';
multiselect.displayValueMember = 'fullName';
multiselect.subtitleMember = 'email';
multiselect.options = users;

2. [key, value] Tuple Arrays NEW

Auto-detected! Simply pass an array of [key, value] tuples. Perfect for simple key-value pairs without creating objects. 

// Simple tuple arrays - no configuration needed!
const languages = [
  ['js', 'JavaScript'],
  ['ts', 'TypeScript'],
  ['py', 'Python'],
  ['go', 'Go']
];

multiselect.options = languages; // Auto-detected as tuples

3. Callbacks for Complex Logic NEW

Use callbacks when you need complex logic to extract values. Callbacks take precedence over members. 

const products = [
  { sku: 'PRD-001', name: 'Laptop', price: 999, inStock: true },
  { sku: 'PRD-002', name: 'Mouse', price: 29, inStock: false },
  ...
];

multiselect.getValueCallback = (item) => item.sku;
multiselect.getDisplayValueCallback = (item) => `${item.name} - $${item.price}`;
multiselect.getDisabledCallback = (item) => !item.inStock; // Disable out of stock
multiselect.options = products;

4. Form Integration - JSON Format NEW

Seamless HTML form integration! Hidden inputs are automatically created and updated. Choose from 3 formats: json, csv, or array. 

<form id="myform">
  <multi-select
    name="skills"           <!-- Creates hidden input with this name -->
    form-value-format="json"  <!-- Default: JSON array -->
    multiple>
  </multi-select>
</form>

// Hidden input value: ["js","ts","py"]

6. Form Integration - Array Format NEW

</multi-select>

7. New Public API Methods NEW

New properties and methods for easier value access:

  • getValue() - Returns single value or array depending on mode
  • selectedValue - Get the selected value(s)
  • selectedItem - Get the first selected item object
  • getSelected() - Get all selected item objects

8. Async Search / Lookup DYNAMIC

Load options dynamically as users type. Perfect for large datasets, API searches, or real-time filtering. 

// Simulate API search
multiselect.searchCallback = async (searchTerm) => {
    const response = await fetch(`/api/users?search=${searchTerm}`);
    return await response.json();
};
